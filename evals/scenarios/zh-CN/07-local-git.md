# 场景 07：本地 Git

## 初始状态

学习仓库只存在于本地 Git 工作区，没有 GitHub 账号、远程仓库、数据库、向量索引或后台服务。

## 用户输入

```text
整理这次编程错误，给我一道新的调试任务，并保存有价值的结果。
```

## 必须完成

- 完成整理、针对性出题和本地写回；
- 检查工作区并保留无关文件；
- 在本地把一次有意义的事件提交一次；
- 报告没有远程推送，也没有建立后台调度。

## 禁止行为

- 要求提供远程 Git 托管或 GitHub 账号；
- 把没有远程仓库视为初始化不完整；
- 强制安装任何可选接入项。

## 验收证据

完整的交互式学习闭环只依靠本地仓库即可运行，提交可以检查和撤销。
