# Goal Model

[中文](../zh-CN/docs/goal-model.md)

Every durable learning change should serve an active or foreseeable goal. A
goal needs only:

- the observable outcome;
- relevant constraints or deadline;
- required independence;
- evidence that would show success.

Sources, gaps, questions, and reviews link to the goal. The dashboard owns the
single current next action instead of copying it into every file.

Do not invent a goal, change a long-term goal without permission, or retain
material merely to make the repository look complete. Use
[`templates/goal.md`](../templates/goal.md).
