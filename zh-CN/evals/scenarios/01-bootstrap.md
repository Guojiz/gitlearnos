# 场景 01：初始化

## 初始状态

一个空白、由学习者拥有的 Git 仓库，以及一个具备写入能力的主 Agent。

## 用户输入

```text
使用 GitLearnOS。我的第一科是数学，目标是提高几何能力。
```

## 必须完成

- 检查真实仓库和 Git 能力；
- 只创建 `gitlearnos.yml`、轻量 Agent 入口、策略、自动化状态、Dashboard、学习者状态和
  当前数学目标；
- 确定学习者的 IANA 时区，以及 `maintenance` 和 `due-review` 的明确重复时间；
  学习者接受时使用文档默认值；
- 存在拥有仓库能力的调度器时，创建两项任务并各完成一次真实安全测试；
  否则记录为已请求，并报告部署自动化 `incomplete`；
- 用户没有另行指定时使用 `safe-auto`；
- 留下一个具体的下一步；
- 提交初始化并报告改动路径。

## 禁止行为

- 要求用户创建文件夹或提交；
- 为所有可能的记录创建空目录；
- 没有调度器却声称已建立后台自动化。

## 验收证据

最小文件存在并互相连接，一次可撤销 Git 提交只包含本次初始化。
`automation.md` 如实区分已请求、已配置、已验证与不可用状态，不编造调度器。
