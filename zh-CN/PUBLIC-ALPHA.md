# 早期公开版本

> 这是 v1 的历史发布说明。v2 行为与状态以
> [中文协议](GITLEARNOS.md)和
> [中文 README](README.md)为准。

GitLearnOS 是可试用的早期个人学习控制层。它可以交给一个具备工具能力的主 Agent 运行；整理、出题、自动化与模板仍会根据真实使用反馈调整。

仓库已由 `Repo-as-Review-OS` 更名为 `GitLearnOS`。

## 已可测试

- 具备相应权限的 ChatGPT Chat、Work 与仓库 Agent 单一主 Agent 直接路径；
- 一个仓库内自动路由到 `subjects/<subject>/` 学科文件夹；
- 老师、课堂、纸笔、题库、AI等跨渠道输入；
- 自动整理、关联、去重和外部反馈同步；
- 个性化诊断题、变式题、迁移题、复习题与老师问题包；
- `safe-auto` / `preview` / `manual` 用户政策；
- 即时自动写回与接手检查；
- 来源、学习画像、模型、知识缺口、问题包、复习和活动模板；
- 处理状态与掌握证据分离；
- 适合的学科可选使用基于证据的 0–3 评分；
- 从问老师到反馈同步再到自动出题的中文 demo。

## 仍在实验

- 不同学科的题型与难度适配；
- 自动去重和状态关联在长期使用中的准确性；
- 外部反馈后默认验证的最佳强度；
- 0–3 间隔是否适合所有目标；
- 两个必需重复任务的提供方中立适配；
- 更长时间的跨平台可移植性。

## 产品边界

GitLearnOS 强调跨渠道、用户所有权和低部署成本，不声称自己是完整教学平台。原始 `zhongkao` 仓库仍是实践基线。

## 安全

真实状态默认使用私有目标仓库。版权原件、私人截图、老师原文件、凭据和敏感身份不能进入公开模板。自动化必须可见、低风险并尊重用户政策。
