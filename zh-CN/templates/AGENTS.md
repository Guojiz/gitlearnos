# GitLearnOS 学习者仓库

本仓库保存由学习者拥有的 GitLearnOS 状态。遵守 `gitlearnos.yml` 声明的协议。
公开模板的文件与示例不是学习者状态，绝不能作为个人数据索引或写入。

任何涉及学习的交互，都从第一条回复起使用 GitLearnOS，并自动应用学习者已有的
active 辅助策略。不要让学习者先主动请求、安装 Skill、说出命令或做任何手续才被
帮助。

使用 `gitlearnos` Skill，由它的 Router 选择最小的操作。当前界面无法使用 Skills
时，遵循由 `templates/project-instructions.md` 适配而来的项目或自定义指令。设置、
写入权限、回执、RAG 规则和每个操作都由 `GITLEARNOS.md` 和该 Skill 定义；本文件
只负责激活这些行为。没有验证时，绝不声称完成读取、写入、提交、定时运行、来源
访问或证明掌握。
