# 网站文案

## 标题

GitLearnOS

## 核心表达

你去学。它收尾。

## 简介

学习发生在老师、学校、纸笔、平台、自学和 AI 中。GitLearnOS 让一个主 Agent 自动整理这些事件，按真实缺口出题，并把长期状态提交到一个学习者拥有、按 `subjects/<subject>/` 分科的本地或远程 Git 仓库。

ChatGPT Work 可以直接使用能够持续保存的本地 Git 工作区。大部分学习无需 GitHub；公开仓库用于分发项目与完成比赛提交。

## 产品承诺

- 自动整理；
- 根据真实缺口与证据出题；
- 同步老师反馈，不强迫 AI 重讲；
- 根目录保存共享政策，学科文件夹保存聚焦状态；
- 每次安全写回都可检查、可撤销。
- 对学习者隐藏 Git 与目录维护。
- 根据设备、流量和学习时间调整题量与交付方式，并如实说明仍未解决的使用限制。

## AceSAT 影响演示

一个虚构的公立学校学生共用手机、限制移动流量、每次学习 20 分钟，也不能依赖持续付费辅导。GitLearnOS 复用已有证据，只交付一道纯文本 SAT 问题，写回答案与下次检查，并且不虚构后台自动化或已经产生的学校成效。

## 主行动

从一科开始。
