# Operating Model

[中文](zh-CN/OPERATING-MODEL.md)

This page is an overview. [GITLEARNOS.md](GITLEARNOS.md) is the canonical
contract.

```text
teachers, class, books, paper, platforms, projects, and AI
→ one replaceable main agent
→ GitLearnOS protocol and Skills
→ one learner-owned Git repository with subject folders
```

The main agent organizes useful evidence, generates targeted questions, runs
or records reviews, reconciles external feedback, and writes back under learner
policy. Live AI tutoring is optional.

Git supplies inspectable history, commits, sync, and rollback. A hosted service,
search index, database, or skill manager is optional. The scheduler provider is
replaceable, but complete learner deployment requires verified recurring
`maintenance` and `due-review` tasks with repository access.
