# 适配器

[English](../../adapters/README.md)

适配器负责把平台无关的 [GitLearnOS 协议](../GITLEARNOS.md)连接到具体环境。它可以改变“如何执行”，不能改变“什么算证据”或“学习事实存在哪里”。

- [Agent 环境](agents/README.md)
- [本地与托管 Git](git/README.md)
- [自动化运行环境](automation/README.md)
- [可选检索与索引](search/README.md)

检索、数据库、向量索引和 Skill 管理器都是可选接入项。它们必须能够从学习者拥有的仓库重建，不能成为学习状态的唯一副本。
