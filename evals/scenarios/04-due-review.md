# Scenario 04: Due Review

## Initial state

A geometry check is due and links to an active goal, prior feedback, and recent
questions. The current run has repository access.

## Learner input

The `due-review` automation or on-handoff check runs.

## Must

- inspect the linked evidence and recent questions;
- generate a small set of fresh, immediately answerable questions;
- explain the selection basis;
- hide answers until an attempt unless policy says otherwise;
- distinguish a real background run from an on-handoff run.

## Must not

- output only “remember to review”;
- repeat the exact demonstration as verification;
- mark the generated questions completed or mastered before an answer.

## Evidence

The delivered questions link to the goal and evidence, remain planned, and the
receipt states which automation mode actually ran.
