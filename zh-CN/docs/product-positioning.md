# 产品定位

GitLearnOS 是一套轻量、由学习者拥有的控制协议：一个有能力、可替换的主
AI Agent，加一个 Git 仓库。

它不取代老师、学校、书籍、练习平台或学习者选择的 AI，而是连接这些渠道中
有价值的证据，生成下一组真正有用的问题，并让长期状态可检查、可撤销。

## 核心承诺

```text
整理真实证据
→ 从当前薄弱点出题
→ 保留作答或外部反馈
→ 以后进行独立验证
→ 提交下一状态
```

成功意味着学习者之后表现得更好，而不是生成更多文件。

## 产品边界

必需：

- 一个具备写入能力的主 AI Agent；
- 一个本地或远程 Git 仓库；
- GitLearnOS 协议；
- 一个目标或真实学习事件。

可选：

- GitHub、GitLab、Gitea 或其他托管平台；
- 已连接的来源系统与检索；
- 真实调度器；
- 数据库、向量索引、OpenSpace 或学科 Skills；
- AI 实时辅导。

核心不要求独立应用、服务器、多 Agent 框架，也不要求学习者亲自操作 Git。

## 所有权模型

根目录文件保存共享政策与当前视图，学科状态放在
`subjects/<subject>/`。原始作答、笔记和外部反馈必须保留；AI 解释只有在
新证据支持时才可修改。
