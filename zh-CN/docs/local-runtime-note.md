# 本地与托管运行边界

[English source](../../docs/local-runtime-note.md)

GitLearnOS 只有一个核心状态层：学习者的 Git 仓库。它可以是本地工作副本，也可以由 GitHub、GitLab、Gitea 或其他服务托管。根目录英文 [`GITLEARNOS.md`](../../GITLEARNOS.md) 是唯一正式协议。

## 本地 Git 能做什么

具备写入能力的本地 Agent 可以完成完整学习闭环：读取当前状态、整理证据、生成问题、记录答案、更新下一步，并提交可逆变更。无需远程仓库。

## 托管服务可能增加什么

托管服务可能增加远程备份、浏览器访问、协作、连接器、CI、Issues 和跨设备交接。只有已配置且获授权时，这些能力才真实存在。

能访问本地文件不代表能访问远程仓库。本地提交不代表已经推送。带日期的任务文件不代表调度器已经执行。

## 其他状态界面

AI 记忆、项目文件、Artifacts、Obsidian 和本地来源文件夹都可以支持工作流。可用时，把大型教材、PDF、扫描件、媒体和长期参考文件放在持久项目来源区或获授权的本地文件夹中。它们是工作界面或来源界面，不是偷偷替代正式学习者仓库的隐藏状态层。

来源留在 Git 之外时，要保存准确的定位和访问状态。原生记忆与可追溯的仓库证据冲突时，以证据为准，并提出记忆修正。

参见[权限与边界](permission-and-boundary.md)和 [Git 适配器](../../adapters/git/README.md)。
