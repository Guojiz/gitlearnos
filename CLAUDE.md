@AGENTS.md

The imported `AGENTS.md` and canonical `GITLEARNOS.md` remain authoritative for
this template repository.

The installable source is the complete `skills/gitlearnos/` folder. When
setting up a learner repository for Claude Code, copy that folder to
`.claude/skills/gitlearnos/`, copy `templates/AGENTS.md` to `AGENTS.md`, and
adapt `templates/CLAUDE.md` to `CLAUDE.md`. Verify that slash-command
autocomplete exposes `/gitlearnos`; a copied file without discovery is only
`source-only`.

Do not write learner state into this public template.
