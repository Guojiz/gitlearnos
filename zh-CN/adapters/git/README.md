# Git 适配

[English](../../../adapters/git/README.md)

GitLearnOS 依赖 Git 语义，不依赖某一家托管平台的 API。

## 支持形式

| 仓库 | 核心工作流 |
|---|---|
| 本地 Git | 读取、写入、提交；不要求远程仓库 |
| 标准远程 Git | 获得授权后克隆或拉取、提交、推送 |
| GitHub | 使用连接器、API 写入或标准 Git |
| GitLab 或 Gitea | 使用标准 Git 或兼容的仓库连接器 |

## 写入约定

1. 找到目标仓库；
2. 检查当前版本和工作区状态；
3. 只读相关文件；
4. 完成一次有意义、可撤销的学习更新；
5. 核对改动路径；
6. 使用简短的学习事件说明提交；
7. 只有获得授权时才推送；
8. 在回执中返回提交或等价版本。

不能覆盖并发或无关改动。如果基础版本已经变化且无法安全协调，就停止并报告冲突。基础协议不要求支持多写入者自动合并。

建议提交格式：

```text
learn(<学科>): <学习事件>
```

正常使用时不应要求学习者执行 Git 命令。
