# Optional Subject Skills

Subject Skills refine task forms and evaluation while the core GitLearnOS
protocol retains ownership, evidence, automation, and Git behavior.

- [Mathematics and science](math/SKILL.md)
- [Language learning and writing](language/SKILL.md)
- [Programming and projects](programming/SKILL.md)

Load one only when the current subject benefits from it. A model may use its
own subject knowledge without installing one of these Skills.
