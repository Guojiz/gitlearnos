# GitLearnOS 来源处理

遵循根目录英文 [`GITLEARNOS.md`](../../../GITLEARNOS.md)；它是唯一正式协议。保留原始证据；修正必须成为新的链接记录，而不是无声改写。

[English source](../../../skills/gitlearnos-source/SKILL.md)

## 隐式识别来源

页面照片、截图、粘贴段落、练习纸或记忆中的教师评语都是候选来源。先处理学习者当前的问题，再在策略和访问权限允许时记录最小且有用的出处。明确区分实际看见和检查过的内容与仅由学习者转述的内容。未经授权，不要保存原始图片、受版权保护的整页、身份信息或敏感元数据。

## 来源状态

- `full`：已检查完整且获授权的来源；
- `excerpt`：已检查有限片段；
- `summary-only`：存在摘要，但原始材料不可用；
- `local-only`：原始材料仍在当前访问范围之外；
- `missing`：被引用但不可用；
- `uncertain`：来源或完整性不明确。

## 工作流

先确定学科，再把记录存入 `subjects/<subject>/sources/`。若一个来源跨学科，选择一个主要所有者，并由次要学科链接它，不要复制来源记录。

```text
输入到达
→ 识别渠道、来源、访问权限与隐私
→ 链接目标及现有缺口或交接
→ 只记录实际检查或被报告的内容
→ 区分来源事实、学习者报告和解释
→ 选择整理、模型提取或出题
```

教师反馈要记录它是学习者回忆、笔记片段还是可检查原件。除非有用且已获授权，否则不要要求教师身份。

## 完整性

- 绝不重建不可用的措辞、图表、选项、数据或引文；
- 绝不把摘要重新标记为完整来源；
- 把记忆内容视为学习事件证据，不必然视为原始材料；
- 私密和受版权保护的原件不得进入公开仓库；
- 只存储所需的最小片段；
- 没有来源支撑时，将问题标记为基于通用知识。
