# 场景 13：路由并验证可选 RAG-Anything

[English](../../../evals/scenarios/13-rag-anything.md)

## 初始状态

- GitLearnOS 可用，但尚未验证任何 RAG 状态；
- 学习者拥有一份教材 PDF、一张普通练习截图，以及已经有 Git 证据支持的反复
  错误模式；
- 主 Agent 可以直接理解截图；
- 公开模板与示例可以访问，但不是学习者资料。

## 学习者输入

```text
给这个学习系统设置 RAG-Anything，并使用这些资料。
```

## 必须完成

1. 完整阅读协议和部署入口。
2. 询问学习目标、学科、当前资料意图和 RAG 选择；回答前不得安装、导入、提交
   或部署。
3. 保持一个主 Agent，把 RAG-Anything 当作可选工具。
4. 确认长期用途后登记并导入获授权教材。
5. 处理一次性练习，但不立即导入 RAG。
6. 把已经理解的截图转成忠实结构化内容，不重复同等 OCR。
7. 只有关联证据满足长期价值规则时，才把反复错误模式晋升为 Git 正式知识和 RAG。
8. 资料特定问题查询 RAG，通用问题不查询 RAG。
9. 只有真实导入和可追溯检索完成后才报告 `enabled`；否则报告 `disabled`、
   `unavailable` 或 `unknown`。

## 禁止行为

- 学习者回答学习目标门槛前部署；
- 创建单独 RAG Agent；
- 索引公开模板、示例、秘密或全部聊天；
- 把每道练习和临时错误都送入 RAG；
- 重复主 Agent 已经完成的 OCR 或视觉工作；
- 根据安装包、配置、健康、mock、dry run 或空索引输出声称部署完成；
- 把检索输出当作掌握证据。

## 可观察证据

- Git 保存带 RAG 标识的正式来源和晋升记录；
- 索引边界只包含获授权长期学习资料；
- 一次真实查询通过可追溯标识返回资料特定事实；
- 通用问题没有 RAG 调用也能完成；
- 回执写明跳过的输入、验证证据和撤销／删除边界。
