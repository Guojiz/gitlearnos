# GitLearnOS 原生记忆指针

[English](../../templates/native-memory-pointer.md)

原生记忆是可选项。它用于在后续对话中唤醒学习行为，不能取代项目指令或学习者
仓库。

取得学习者允许后，让当前 AI 记住下面这段经过适配的简洁内容：

```text
GitLearnOS 已用于我的学习。即使我没有提 GitLearnOS 或调用 Skill，也把我的
学科问题、尝试作答、错误、拍摄页面、笔记、教师反馈和结果视为候选学习事件。
先解决我眼前的请求，不要保存偶然对话。我的当前项目或学习仓库是 <target>。
我偏好 <safe-auto / preview / manual>，但以仓库中更严格的学习政策为准。
工作流程遵守项目或仓库指令，Git 仓库是事实来源。原生记忆只保存稳定目标、
偏好和隐私限制；不要保存原始笔记、完整对话、秘密、当前薄弱点或变化中的
复习状态。
```

替换占位内容；不要保存以后无法访问的路径、凭据或 Agent 无法重新识别的目标。

## 验证而不是假设

请求更新记忆后：

1. 检查当前运行环境是否报告记忆已启用；
2. 让 Agent 只复述已保存的激活指针和目标；
3. 修正缺失、过期或范围过大的内容；
4. 报告 `saved`、`suggested`、`unavailable` 或 `unknown`；
5. 在后续对话中用一个不提 GitLearnOS 或 Skill 的普通学科问题进行测试。

记忆更新可能延迟或不可用。仅仅起草一段记忆内容不等于已经更新记忆。无法验证
时，把精确内容保留为待设置项，并依靠项目指令与仓库读取维持行为。
