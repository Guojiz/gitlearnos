# GitLearnOS 标准 — 学习判断力

遵循 Router 的核心契约。本参考文件编码所有其他操作在自身参考文件不足以判断时
应参考的判断层：什么重要、什么不重要、什么算有质量、什么时候该归档。
本文件不重新定义协议规则。

[English source](../../../../skills/gitlearnos/references/standards.md)

## 何时使用

以下情况加载本参考文件：

- 判断观察到的输入是否值得记录为学习事件；
- 在多个候选中排定复习、检查或教学的优先级；
- 判断学习记录是否达到质量标准；
- 决定清理记录中的噪音，或归档旧知识。

不必每次小操作都加载。只有操作专属参考文件没有直接给出判断时才查阅。

## 优先级顺序

分配注意力、排列仪表盘队列或选择下一步教什么时使用这个顺序。排位越高越优先。

1. **会阻塞后续学习的误解** — 学习者把 X 当作 Y，而不仅是"还不知道 X"。
   有明确混淆的错误答案，优先于缺失的知识点。
2. **逾期或今日到期的计划复习** — 过了计划日期，或今天到期。
3. **即将到期的计划复习** — 在配置窗口内。
4. **有新证据的开放缺口** — 上次检查后有新观察记录。
5. **未来的复习** — 已计划但离到期尚早。
6. **无紧急度的新工作** — 没有截止日期的全新缺口或模型草稿。

同一桶内：混合紧迫度 × 杠杆率（能打通多少后续）；保持温和（不让两个硬任务
连在一起）；题材多样性和稳定 ID 打破平局。无实质变化时不重排。

## 质量门禁

记录学习事件前，四个问题必须全部通过。

1. **结论**：有没有长期价值——学到了什么、确认了什么，或发现哪里错了？
2. **证据**：有没有链接的来源、观察或回答？
3. **变化**：有没有改变某个缺口、模型、复习或下一步？
4. **许可**：学习者有没有要求不保存？

**跳过**的情况：偶然聊天、与已有状态重复（更新已有记录即可）、只是推理过程、
学习者明确说不。

**不确定时**：记录最小事件，标注 `evidence_type: not-assessed` 和
`next_action: needs-clarification`。不要从不确定的材料构建完整的
缺口-模型-复习链。

## 精简纪律

学习记录是**结论及其证据**，不是产生结论的过程。

### 删除

- **思维链**："我一开始觉得是 X，后来试了 Y" → 只保留结论。
- **变更叙述**："从 v3 更新到 v4 是因为……" → Git 有历史；记录只需要当前版本。
- **临时上下文**："今天会话中我们讨论了……" → `occurred_at` 字段已记录时间。
- **装饰性文字**："有趣的是""值得注意的是" → 删掉。
- **Agent 自我报告**："审查证据后，Agent 认定……" → 记录本身就是认定结果。

### 保留

- **不变量**：获得或修订后的稳定理解。
- **前置/后置条件**：应用前和应用后分别需要满足什么。
- **已链接证据**：来源材料的 ID 和路径。
- **缺口**：仍未确认、有误或缺失的部分。
- **冲突**：与当前理解矛盾或限制当前理解的证据。

### 检验

回读记录。如果开头是"但首先……"或"在考虑了……之后……"，继续精简。如果能
不借助叙述前缀回答"学到了什么、证据在哪、还有什么要做"，就是干净的。

## 归档生命周期

按**未来复用价值**判断，不按时间长短。

| 状态 | 条件 | 动作 |
|---|---|---|
| **活跃** | 链接到开放缺口、30 天内复习或未解决冲突 | 保持轮换 |
| **周期** | 已证明一次，尚未迁移；30–90 天内复习 | 保留，慢轮换 |
| **永久** | 已证明 + 已迁移；模型 `active`；无冲突 | 保留，停止复习 |
| **删除** | 一次性噪音；已被更好记录完全取代；从未链接到任何缺口或复习 | 移除 |

### 晋升规则

- 活跃 → 周期：所有链接复习均已独立通过，同一缺口 30 天无新观察。
- 周期 → 永久：已证明 + 已迁移，模型为 `active`，无未解决冲突。
- 永久 → 活跃：出现新的矛盾观察，或链接模型退回到 `draft`。
- → 删除：从未链接到任何缺口、复习或模型；或被带有 `supersedes` 链接的
  替代记录完全取代。

绝不删除仍被活跃缺口、复习或模型链接的记录。先解除链接，再删除。

## 反模式

拒绝以下做法。它们看起来像干活，但不会改善学习。

**记录噪音**：把聊天记录当学习事件；保留完整文稿而非规范化记录；每次小失误
都单独建缺口（等出现规律再说）。

**虚假掌握信号**：把 AI 讲解当作学习者已理解；从一次观察晋升模型；把外部
解答标注为 `demonstrated`。

**空转**：没有到期内容时制造填充题（`skipped` 是合法结果）；无变化时重排
仪表盘；创建重复记录而非更新已有记录。

**过早结构化**：从一次随意提问构建完整缺口-模型-复习链；迁移检查前就晋升
模型；没有延期独立证据就归档为"已掌握"。

## 复习前最小检查

执行复习前，只检查相关项：

1. **到期了吗？** 检查计划日期。没到期且无紧急原因 → 跳过。
2. **链接到什么？** 只读链接的缺口、模型和历史尝试——不扫整个学科。
3. **成功标准是什么？** 按保存的答案键或评分标准评分，不凭通用知识。
4. **什么变了？** 上次尝试后同一缺口仅有的新证据。

不要扫描全部学科、重读完整仪表盘、评分时生成新题目、或无变化时重排队列。
