# 自动化运行环境矩阵

[English](../../docs/automation-runtime-matrix.md)

| 运行环境 | 仓库权限 | 合法结果 |
|---|---:|---|
| 有能力的交互式 Agent | 有 | 即时工作与回退接手检查；重复部署仍不完整 |
| 拥有工具的计划 Worker | 有 | 配置并验证真实重复 `due-review` 与 `maintenance` |
| 仅提示词调度器 | 无 | 只能提醒或交接，绝不能标记 `verified` |
| 本地 cron 或 CI | 取决于已配置 Agent 与凭据 | 只有一次观察到的仓库测试运行后才能 `verified` |

所有环境实现[自动化适配器](../adapters/automation/README.md)中的同一任务意图。不能声称产生了实际上不存在的文件、题目、提交或调度。

设备休眠、断网或提供方延迟可能错过发生项。下一次具备能力的 Worker 可以使用
原发生项幂等键补跑一次，否则报告跳过；不能再次交付同一到期证据。
