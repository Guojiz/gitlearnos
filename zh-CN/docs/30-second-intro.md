# 30 秒理解 GitLearnOS

GitLearnOS 是一套 Git 原生学习协议。一个有能力的主 AI Agent，把真实学习
事件转成互相连接的证据、针对性问题、作答记录和可撤销更新，并保存在学习者
拥有的仓库中。

学习者无需操作 Git。Agent 读取当前版本，只写入有价值的状态，为一个有意义
的学习事件创建一次提交，并如实汇报实际发生的动作。

仓库可以在本地，也可以托管在任何标准 Git 服务上。GitHub 只是可选托管方式。
数据库、向量检索、服务器、调度器、多 Agent 运行环境和 OpenSpace 都是可选项。

成功不是笔记越来越多，而是学习者能在后续问题中独立表现得更好，并且结论有
可追溯证据。

[中文协议](../GITLEARNOS.md)为行为准则。
