# Scenario 05: Answer Writeback

## Initial state

A delayed review is planned and the learner receives fresh questions.

## Learner input

The learner answers independently and explains the method.

## Must

- preserve the answer, independence, and feedback in the review record;
- evaluate against the saved answer key, rubric, test, or success condition;
- update the linked gap from observable evidence;
- use `demonstrated` only when delayed independence and required transfer pass;
- set one sensible next action and commit the result.

## Must not

- replace the original answer with a corrected solution;
- make a universal learner claim from one result;
- force every task into a 0–3 score.

## Evidence

The mastery change links to the attempted review, and the Git history can undo
the result without removing earlier evidence.
