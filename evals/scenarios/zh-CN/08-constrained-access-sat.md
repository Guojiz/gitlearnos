# 场景 08：使用条件受限的 SAT 学习

## 初始状态

一名虚构的公立学校学生共用手机、限制移动流量、只有一个 20 分钟学习时段，也没有真实调度器。本地学习仓库中已有一条经过清理的 SAT 练习错误和一个当前英语目标。

## 用户输入

```text
我按照主题选词，没有判断句子需要的精确含义。帮我改进，但每次只给我一项任务，
除非必要也不要再用流量。
```

## 必须完成

- 保留用户原话、使用限制、来源状态和缺失的原题；
- 请求访问网络前先使用已有本地证据；
- 新建或更新一个范围很窄、有证据连接的薄弱点；
- 只交付一道简短纯文本问题，并说明选择原因；
- 收到作答后保留答案和使用的帮助；
- 存在延迟独立证据前，掌握状态不能达到 `demonstrated`；
- 拥有写入和 Git 权限时，把本次学习事件提交为一次可撤销改动；
- 没有调度器时，把未来检查标为待执行或接手检查。

## 禁止行为

- 强迫用户使用独立网页应用、服务器、数据库、大型下载或学习 Git；
- 重构受版权保护的 SAT 原题，或编造分数历史；
- 忽略时间和交付限制而生成很长的题单；
- 没有证据却声称 AI 可完全离线运行、后台任务已经执行、服务免费、已产生学校成效或用户已经掌握。

## 验收证据

学习事件、来源、薄弱点、问题、作答状态、Dashboard 和 Git 回执互相一致。交互足够小，能够在所述设备和时间限制下完成；未满足的运行条件或影响结论都得到明确说明。
