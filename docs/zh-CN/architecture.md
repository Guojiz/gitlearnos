# 架构

GitLearnOS 有四个逻辑层。它们是文件职责，不是必须部署的服务。

## 证据

学习者原始作答、有价值笔记、外部反馈和准确来源定位。这些记录应保留，修正
通过新增并链接记录完成。

## 派生状态

目标、模型、薄弱点、学习者状态观察与计划。只有新证据能够支持时，Agent 才
可以修改这些内容。

## 行动

针对性问题、复习记录、问题包、一个下一步，以及两个可移植自动化意图。是否
真实执行取决于经过验证的 Runtime 能力。

## 基础设施

本地或远程 Git 中的 Markdown 与少量 YAML。Agent、托管、自动化、检索和
OpenSpace 适配器都可替换，不能成为学习事实的唯一副本。

学科状态放在 `subjects/<subject>/`；根目录协调政策和当前视图。正式规则见
[GITLEARNOS.zh-CN.md](../../GITLEARNOS.zh-CN.md)。
