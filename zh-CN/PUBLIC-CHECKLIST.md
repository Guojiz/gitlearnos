# 公开前检查清单

这份清单用于把 GitLearnOS 发到朋友圈、学校群聊、研究群或开源社区前快速检查。

## 1. 定位是否清楚

- [ ] 是否说明它是一套 Git 原生学习协议？
- [ ] 是否避免把它说成普通资料库？
- [ ] 是否说明它不是 ChatGPT 专属，也不是 Obsidian 专属？
- [ ] 是否明确标注 `v2.0-draft`，没有暗示已正式发布？

## 2. 入口是否清楚

- [ ] README 是否能在第一屏讲清楚？
- [ ] 是否有“复制给 AI 的提示词”？
- [ ] 是否链接了 `OPERATING-MODEL`？
- [ ] 是否链接了 demo？
- [ ] 是否链接了贡献指南？

## 3. 安全是否清楚

- [ ] 是否提醒真实学习资料用私有仓库？
- [ ] 是否提醒不要公开老师文件、教材、私人截图、真实考试记录？
- [ ] 是否说明本地材料只在需要时提供最小摘录？
- [ ] 是否说明 AI 不能假装读过无法访问的本地文件？

## 4. 贡献路径是否清楚

- [ ] 是否有 `CONTRIBUTING.md`？
- [ ] 是否有 `zh-CN/CONTRIBUTING.md`？
- [ ] 是否有 issue 模板？
- [ ] 是否说明可以贡献 demo、模板、翻译、自动化提示词和反馈？

## 5. demo 是否清楚

- [ ] 是否有一个最小可读 demo？
- [ ] demo 是否不含真实私人资料？
- [ ] demo 是否展示目标、模型、题单、控制台和复习安排？

## 6. 发出去时怎么说

推荐文案：

```text
我正在测试 GitLearnOS v2。

它是一套 Git 原生学习协议，不是普通资料库，也不只支持 GitHub。

一个有能力的主 AI Agent 会整理可追溯证据、从真实薄弱点出题、记录作答与
反馈，并把可撤销状态提交到本地或远程 Git 仓库。

目前有一个中文轻量 demo，可以直接把仓库丢给 AI，让它解释并尝试帮你搭建自己的学习 OS。

欢迎提 issue、贡献 demo、模板、自动化提示词或使用反馈。
```

## 7. 当前建议

当前分支可以按以下状态分享：

```text
v2.0-draft
```

不要包装成最终成品。
