# 学习循环

GitLearnOS 不应该只是复习系统。

复习是学习的底层动作。真正的目的，是回到旧材料，并从旧材料里长出新的理解。

## 原则

学习应该形成这个循环：

```text
学习
→ 作答并保留当时判断
→ 诊断缺失信息或第一处推理链断裂
→ 链接同型证据
→ 归纳模型、答题结构和有证据支持的结论
→ 之后在足够新的任务中主动回忆并应用
→ 根据反馈修订诊断与模型
```

这是循环，不是每道练习都必须进入的流水线。普通一次性题目保持轻量。反复观察
或明确可复用的方法才需要归纳；间隔后的独立迁移才支持掌握判断。

## 复习不是终点

复习不是重复旧答案。

好的复习应该产生：

- 更清楚的模型；
- 更准确的识别信号；
- 新的变式题；
- 更强的解释；
- 和其他主题的连接；
- 新的练习任务。

抄下答案不是模型。有价值的归纳会保留学习者原判断，链接证据，写清识别信号与
边界，并改变学习者或 Agent 在后续任务中的行动。

## 有研究依据，但不承诺结果

主动提取与延迟检查可以帮助长期保持，变式练习可以帮助区分不同题型。这些研究
不能支持关于年级排名、提分幅度或固定掌握百分比的承诺。讲解、总结、创建模型
和 RAG 检索是学习输入，不是掌握证据。

一手研究：[Roediger 与 Karpicke 的延迟保持研究](https://doi.org/10.1111/j.1467-9280.2006.01693.x)、
[Karpicke 与 Roediger 的重复提取研究](https://doi.org/10.1126/science.1152408)，
以及 [Rohrer 与 Taylor 的数学混合练习研究](https://doi.org/10.1007/s11251-007-9015-8)。

## 温故而知新

旧材料应该成为新学习的燃料。

AI 应该问：

1. 用户以前懂了什么？
2. 什么又忘了？
3. 可以提取出什么规律？
4. 可以生成什么新问题？
5. 应该和当前目标建立什么连接？

## 仓库行为

仓库不应该把旧知识冻住。

它应该允许文件不断演化：

- 原始作答和反馈保持不变；
- AI 派生卡片和模型可依据链接证据修改或合并；
- 薄弱点可以解决，但掌握状态仍需单独证据；
- 非活跃项目可以归档，但不抹去历史；
- 复习项目可以生成新任务。

## 实用规则

系统温习旧材料，是为了让用户从中学到新东西。
