# GitLearnOS Skills

[English](../../skills/README.md)

一个主 Agent 先读取根目录英文 `GITLEARNOS.md`，再加载 Router，并且只加载当前任务真正需要的最小 Skill。英文协议是唯一正式规则；本目录是保持同一行为的中文译本。

```text
gitlearnos              意图路由
gitlearnos-setup        初始化或迁移
gitlearnos-organize     收集、整理、去重、同步外部反馈
gitlearnos-question     给学习者出题或生成外部问题包
gitlearnos-session      可选的实时 AI 辅导
gitlearnos-source       来源、可用状态与隐私
gitlearnos-model        可复用理解
gitlearnos-review       执行、评价、安排复测并写回
gitlearnos-maintenance  一致性、自动化健康与安全撤销
```

核心产品能力是整理、出题和自动写回。实时辅导是可选项；职责划分不代表必须使用多个 Agent。
