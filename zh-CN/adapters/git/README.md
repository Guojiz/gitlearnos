# Git 适配

[English](../../../adapters/git/README.md)

GitLearnOS 依赖 Git 语义，不依赖某一家托管平台的 API。

## 支持形式

| 仓库 | 核心工作流 |
|---|---|
| 本地 Git | 读取、写入、提交；不要求远程仓库 |
| 标准远程 Git | 获得授权后克隆或拉取、提交、推送 |
| GitHub | 使用连接器、API 写入或标准 Git |
| GitLab 或 Gitea | 使用标准 Git 或兼容的仓库连接器 |

即使在同一产品中，ChatGPT Chat、Work、Codex 与其他 Agent 也可能提供不同仓库工具。必须检查当前界面。看不到 Git 技术细节不代表 Git 不存在；产品标签也不能证明 Git 一定可用。

## 写入约定

1. 找到目标仓库；
2. 检查当前版本和工作区状态；
3. 只读相关文件；
4. 完成一次有意义、可撤销的学习更新；
5. 核对改动路径；
6. 使用简短的学习事件说明提交；
7. 只有获得授权时才推送；
8. 在回执中返回提交或等价版本。

不能覆盖并发或无关改动。如果基础版本已经变化且无法安全协调，就停止并报告冲突。基础协议不要求支持多写入者自动合并。

建议提交格式：

```text
learn(<学科>): <学习事件>
```

正常使用时不应要求学习者执行 Git 命令。

## 何时接入 GitHub

单设备私密学习只需本地 Git。学习者需要以下能力时，再添加私有 GitHub 远程仓库或其他托管平台：

- 异地备份或跨设备连续性；
- 教师、导师或同伴审阅聚焦材料；
- 共享课程资料、评分标准或项目作品；
- 通过 Pull Request、Issues 或 CI 进行明确协作；
- 发布经过脱敏的公开示例。

共享课程仓库与私密学习者仓库应分开。只有确认远程目标、访问权限、可见性和策略后才能推送。
