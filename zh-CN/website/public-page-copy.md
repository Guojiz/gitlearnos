# 网站文案

## 标题

GitLearnOS

## 核心表达

你去学。它收尾。

## 简介

学习发生在老师、学校、纸笔、平台、自学和 AI 中。GitLearnOS 让一个主 Agent 无需等待 Skill 命令就能注意到这些事件，引导下一步，按真实缺口出题，并把长期状态提交到一个学习者拥有、按 `subjects/<subject>/` 分科的本地或远程 Git 仓库。

当前项目或会话具备已验证仓库权限时，ChatGPT Chat 或 Work 都可以使用 Git。即使没有 Skills，Chat 也适合日常问题、答案、页面照片和反馈；Work 适合引导式设置与较大的多文件任务。Project Sources 保存大型教材、PDF 和扫描件。大部分学习无需 GitHub，但私有远程仓库有助于备份、跨设备连续性、教师审阅和共享课程协作。

## 产品承诺

- 自动整理；
- 无需显式调用也能识别有价值的学习事件；
- 用记忆作主动触发，用 Git 作事实来源；
- 引导设置和下一项有价值的学习行动；
- 根据真实缺口与证据出题；
- 同步老师反馈，不强迫 AI 重讲；
- 根目录保存共享政策，学科文件夹保存聚焦状态；
- 每次安全写回都可检查、可撤销。
- 对学习者隐藏 Git 与目录维护。
- 根据设备、流量和学习时间调整题量与交付方式，并如实说明仍未解决的使用限制。

## AceSAT 影响演示

一个虚构的公立学校学生共用手机、限制移动流量、每次学习 20 分钟，也不能依赖持续付费辅导。GitLearnOS 复用已有证据，只交付一道纯文本 SAT 问题，写回答案与下次检查，并且不虚构后台自动化或已经产生的学校成效。

## 主行动

从一科开始。
