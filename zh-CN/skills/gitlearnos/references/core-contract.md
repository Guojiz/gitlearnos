# GitLearnOS 核心契约

[English source](../../../../skills/gitlearnos/references/core-contract.md)

模板仓库的正式 `GITLEARNOS.md` 不可访问时使用本精简契约。可访问时仍以正式
协议为准。

## 激活与权限

每次交互都静默判断问题、作答、页面、笔记、反馈、结果、订正、目标变化或反复
困难是否有持久价值。先解决眼前需要。不要保存偶然聊天或学习者明确要求不保存的
内容。

`gitlearnos.yml` 是唯一学习者配置、授权和能力声明。不要从第二个文件推断权限。文件
缺失或格式错误时使用 `manual` 并报告，不得猜测：

- `safe-auto`：只做小型、可逆且明确有用的写入；
- `preview`：展示拟议改动但不写入；
- `manual`：明确批准后才写入。

删除、覆盖证据、大范围重构、修改长期目标或配置、发布、改可见性、对外发送、
密钥或敏感身份信息都要先询问。

## 规范学习状态机

每条持久学习路径都必须是明确且可链接的状态转移：

```text
event（观察证据）
  → gap（open / needs-check / resolved）
  → model draft（可能成立，未晋升）
  → model active（满足晋升证据）
  → review planned（保存新问题）
  → transfer attempted（延迟且独立的结果）
  → mastery learning | demonstrated
```

每个 `event`、`gap`、`model`、`review` 都要有稳定机器可读的 `id` 与规范
`path`。派生记录使用 `depends_on`、`composes_with` 链接；替代旧记录使用
`supersedes`；模型修订使用单调递增的 `version`。`conflicts` 记录阻止晋升或掌握
转移的证据。仪表盘行、没有答案的分数、讲解或外部解决本身都不是状态转移。

## 证据与掌握

- 保留学习者作答、原始笔记和外部反馈。
- 修正保留材料时新增链接记录，不能静默覆盖。
- AI 总结、模型、缺口、仪表盘和计划可随证据变化。
- 重要结论链接可追溯证据；证据缺失保持 `unknown` 或 `needs-verification`。
- `demonstrated` 要求延迟后的独立成功；目标要求迁移时还要有迁移成功。阅读、
  完成、立即模仿、外部解决和有辅助成功仍是 `learning` 或未评估。
- 讲解、总结、创建模型和 RAG 检索都不能证明掌握。保留学习者实际判断与结果，
  把缺失事实或推理断点当作可修订诊断。表面错误是信号，不是知识缺口：保留
  互竞假设，使用鉴别性追问；剩余类别共享干预时可停问；只有正向证据且会改变
  教学动作的替代已被削弱时才写 `supported`。被否定的假设留在记录中。与旧掌握
  状态矛盾的新证据应打开矛盾审讯，不能只降分。


## 最小读取与写入

读取 `gitlearnos.yml`、根仪表盘、当前学科目标和直接相关证据。状态放在
`subjects/<subject>/`；跨学科材料选择一个规范所有者并链接，不复制。大型原件放
在获授权来源区；Git 保存精简状态、定位信息、选定证据与历史。

写入前检查 Git 状态并保留无关工作。每个有意义学习事件优先一次提交。重复输入
更新或链接现有状态，不产生重复。只有远程和授权都确认时才推送。

## 复测日期与自动化诚实边界

学习者未指定日期时使用确定的本地默认值，并记录原因：新缺口或错误/有辅助结果为
下一个本地日；部分结果或外部解决为三天后；独立正确但尚无迁移为七天后；迁移
检查为该次作答七天后。事件时间或时区未知时使用 `noSignal`，不能猜日期。

即时工作只发生在当前交互。后台工作只有真正创建可访问仓库的调度器才存在。
为 `maintenance`（默认 21:30）和 `due-review`（默认 07:00）指定 IANA 时区和本地
重复时间。请求计划、模式和交付偏好写入 `gitlearnos.yml`；观察到的任务 ID、下次
运行与测试证据写入 `automation.md`。没有真实任务和安全试运行时，自动化为
`incomplete`。没有到期证据或实质变化时返回 `skipped`，不生成内容、通知、时间戳
变化或提交。

## 仪表盘队列与展示

`dashboard.md` 是生成视图，不是第二真相源。队列行只能包含规范 ID 和仓库路径，
不能带样例正文、答案或派生状态。仅在证据、日期、依赖、重要性、薄弱程度或目标
变化时重排。确定性优先级为：未满足先修；逾期/今日 planned 复习；即将到期复习；
未来复习；open 缺口；最后是新任务。同桶混合杠杆（`importance × weakness`）和
温和度，平局按学科多样性再按稳定 ID。无变化维护不得重排。

只有打开队列是有帮助的下一步时才写 `Panel: expand`，否则写 `Panel: collapse`。
学习者手动切换持续有效，直到 Agent 记录实质 `queue_revision` 或出现紧急到期项。
展开/折叠是展示状态，不是学习状态。
