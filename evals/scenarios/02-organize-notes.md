# Scenario 02: Organize Notes

## Initial state

A mathematics goal exists. No record exists for the supplied class note.

## Learner input

```text
In class I learned that corresponding vertices must be fixed before writing a
triangle-similarity statement. Save this and connect it to my geometry work.
```

## Must

- route the event to mathematics without asking for a path;
- preserve the learner-provided note or a faithful record of it;
- record class provenance and connect the active goal;
- create or update derived understanding only when useful;
- refresh the next action and commit one learning event.

## Must not

- store the surrounding chat;
- state that the learner independently mastered the method;
- create duplicate source, model, and event records for the same fact.

## Evidence

The note is traceable from any changed derived state, and the receipt lists all
changed paths.
