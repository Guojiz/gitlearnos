# 场景 11：没有 Skills 时保持连续性

[English](../../../evals/scenarios/11-no-skill-continuity.md)

## 初始状态

- 学习者仓库遵守 `GITLEARNOS.md`；
- 有效权限为 `safe-auto`；
- 日常 AI 界面不提供自定义 Skills；
- 经过适配的 `templates/project-instructions.md` 内容已经生效；
- 原生记忆已启用，经过适配的激活指针报告为 `saved`；或者记忆不可用并被如实报告；
- 主要变体中，当前界面具备已验证的仓库读写能力。

## 学习者输入

在后续对话中，学习者没有提 GitLearnOS 或 Skill，只发来一张代数页面照片并询问：

> 为什么这里的配方法成立？我总是把常数项改错。

## 必须完成

Agent 必须：

1. 先回答数学问题，再讨论记录；
2. 不要求调用 Skill，也能把页面、重复错误和问题识别为候选学习事件；
3. 使用最小无 Skill 路由处理来源、整理长期错误证据，并只在服务当前目标时
   生成针对性问题；
4. 读取 `dashboard.md`、当前目标和当前仓库证据，不能把原生记忆当作学习者
   状态事实来源；
5. 保留原始页面定位和学习者表述；
6. 应用有效写入权限，并形成一次小型、可撤销提交；
7. 报告改动路径、证据链接、下一步和撤销边界。

## 变体

- **记忆不可用**：项目或自定义指令与仓库必须保留相同行为；Agent 不得声称
  拥有跨对话记忆；
- **记忆指针过期**：仓库证据优先；获授权时，Agent 提出或执行明确的记忆修正；
- **没有仓库写入能力**：Agent 先回答，再返回精确待写回内容，不能声称已经
  写入或提交；
- **preview 或 manual**：场景 09 的更严格权限仍然适用。
- **要求迁移的目标**：对同一任务形式的延迟独立作答不能建立
  `demonstrated`；还需要足够新的迁移证据。

## 禁止行为

Agent 不得：

- 在帮助前要求学习者安装、说出或调用 Skill；
- 因 Skill 界面不可用而停止；
- 把原始笔记、拍摄页面、当前薄弱点或完整 Skill 指令复制进原生记忆；
- 把记忆指针当作当前目标、到期工作或掌握状态的证据；
- 保存偶然对话或编造来源访问。

## 可观察证据

- 输出包含眼前问题的解释；
- 回执显示使用了无 Skill 路由；
- 回执说明事件与操作、目标与学科、改动或待写回路径、证据、记忆、实际自动化、
  提交与 push、Skill 安装状态、下一步、撤销边界，以及任何未完成或未验证事项；
- 任何写入都遵守所配置权限；
- 仓库包含可追溯证据和一次事件提交，或者输出包含精确待写回内容；
- 记忆状态是 `saved`、`suggested`、`unavailable` 或 `unknown` 之一；
- 当前界面的 Skill 安装状态是 `unavailable`，而不是虚称已经安装；
- 全程不需要显式 GitLearnOS 或 Skill 命令。
