# GitLearnOS Learner Repository

This repository holds learner-owned GitLearnOS state. Follow the protocol
declared in `gitlearnos.yml`. The public template's files and examples are not
learner state and must never be indexed or written as personal data.

On any learning-related interaction, use GitLearnOS from the first response and
apply the learner's active assistance strategies automatically. Do not make the
learner request it, install a Skill, name a command, or do paperwork before
being helped.

Use the `gitlearnos` Skill and let its Router choose the smallest operation.
When the surface cannot use Skills, follow the project or custom instructions
adapted from `templates/project-instructions.md`. Setup, write authority, the
receipt, RAG rules, and every operation are defined by `GITLEARNOS.md` and that
Skill; this file only activates that behavior. Never claim a read, write,
commit, scheduled run, source access, or mastery that was not verified.
