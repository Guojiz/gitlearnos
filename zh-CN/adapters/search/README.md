# 可选检索适配器

[English](../../../adapters/search/README.md)

GitLearnOS 核心直接读取已链接的 Markdown。只有仓库大到仅靠路径和链接不够时，
才需要检索。

检索适配器可以索引来源、模型、薄弱点、复习和事件，但必须满足：

- 索引可从 Git 重新构建；
- 检索结果只是定位，不自动成为学习证据；
- 访问控制与原仓库及来源一致；
- 学习者记录不能离开已批准边界；
- 搜不到不能被当成“不存在证据”的证明。

向量检索、关键词检索和托管检索系统都遵守这些边界。v2 验收不要求任何一种。

RAG-Anything 是多模态学习资料的建议但可选本地适配器。其索引还可以包含获授权
原始教材、课程包、笔记和从 Git 晋升的正式知识。遵循[部署卡](../../docs/rag-anything.md)
和 Skill 的 [`rag.md`](../../skills/gitlearnos/references/rag.md) 决策规则。不能
索引公开模板、示例、未授权文件或临时练习。包导入或空健康检查不算部署证据；
必须验证一次真实获授权导入和一次可追溯检索。
