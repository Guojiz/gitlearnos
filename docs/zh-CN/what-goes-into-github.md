# 学习仓库保存什么

这个路径为了兼容旧链接而保留。规则适用于本地和远程 Git，不只适用于 GitHub。

## 放进仓库

- 目标与学习政策；
- 来源记录和准确定位；
- 学习者原始作答、有价值笔记与外部反馈；
- AI 提炼的模型与当前薄弱点；
- 已布置或已作答的问题，以及后续复测；
- 自动生成的 dashboard 与经过验证的自动化回执。

## 适合留在仓库外

- 大型原始文件；
- 受版权保护的书籍或教师材料；
- 私密截图和原始导出；
- 密钥与无关身份信息；
- 普通聊天记录和隐藏推理。

来源留在仓库外时，记录它的位置、当前 Agent 能否访问，以及结论实际使用了
哪一段。不能声称读过无法访问的材料。

公开 GitLearnOS 模板绝不保存个人学习状态。
