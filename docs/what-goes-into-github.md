# What Goes Into the Learning Repository

This path is retained for old links. The rule applies to local and hosted Git,
not only GitHub.

## Keep in the repository

- goals and learner configuration;
- source records and accurate locators;
- original learner answers, useful notes, and external feedback;
- AI-derived models and current gaps;
- assigned or attempted question sets and later checks;
- generated dashboards and verified automation receipts.

## Keep outside when appropriate

- large source files;
- copyrighted books or teacher materials;
- private screenshots and raw exports;
- secrets and unrelated identity data;
- ordinary chat transcripts and hidden reasoning.

When a source stays outside, record where it is, whether the current agent can
access it, and exactly which excerpt informed a conclusion. Never claim to
have read unavailable material.

The public GitLearnOS template never receives personal learner state.
