# 从这里开始

[English](../START-HERE.md)

GitLearnOS 通过一个具备 Git 仓库权限的现有 AI Agent 运行。

## Agent 路径

1. 阅读[中文协议](GITLEARNOS.md)。
2. 找到学习者的目标 Git 仓库或本地工作区。
3. 检查真实的读取、写入、提交、推送、来源和调度能力。
4. 读取目标策略、Dashboard、当前学科目标和最低限度的相关证据。
5. 环境支持 Skills 时，使用 [GitLearnOS 中文 Skill](skills/gitlearnos/SKILL.md)。
6. 完成安全操作，把一次有意义的学习事件提交为一次改动，并返回规定回执。

## 重要边界

- 个人状态只能写入学习者仓库。
- GitHub 只是可选 Git 托管平台，不是核心依赖。
- 普通聊天不是学习记录。
- 原始作答、笔记和外部反馈必须保留。
- 到期自动化应直接生成具体问题，而非只发送提醒。
- 没有真实写入或调度能力时，必须诚实返回待处理内容。

可复制的初始化指令见[快速开始](QUICKSTART.md)。
