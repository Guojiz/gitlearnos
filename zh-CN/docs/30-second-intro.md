# 30 秒理解 GitLearnOS

GitLearnOS 让一个有能力的主 AI Agent 使用学习者拥有的 Git 记忆。它把问题、作答
尝试、笔记、更正或老师反馈等真实学习事件，转成互相连接的证据、一个有用的下一
个问题和一次可撤销的状态更新。

核心版设置刻意很小：一个私有本地 Git 仓库、协议和项目指令、一个学科或目标，以
及确实能够读写的 Agent。日常学习时，学习者无需操作 Git。GitHub、RAG、数据库、
服务器和调度器都是可选项。

Agent 先回答眼前问题。只有目标和证据清楚时，`safe-auto` 才允许安全、可撤销的
写回；`preview` 只提出变更；`manual` 等待批准。即时更新属于当前 Agent；重复的
后台运行属于外部仓库 Worker，提醒或会话内调度都不能证明它已经执行。

请从[快速开始](../QUICKSTART.md)中的唯一标准设置指令开始，并以
[GITLEARNOS.md](../GITLEARNOS.md)为行为协议。
