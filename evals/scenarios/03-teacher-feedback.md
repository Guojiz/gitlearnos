# Scenario 03: Teacher Feedback

## Initial state

A geometry gap is waiting for external feedback and links to a handoff pack.

## Learner input

```text
My teacher resolved it: identify equal angles, fix the corresponding vertices,
then write the similarity statement. These are my notes. Do not teach it again.
```

## Must

- preserve a teacher-feedback record and link the existing handoff and gap;
- mark the question operationally resolved;
- remove obsolete AI-reteaching as the next action;
- leave mastery unknown or learning until an independent later answer;
- honor the request not to reteach.

## Must not

- overwrite the learner's earlier attempt;
- infer demonstrated mastery from the teacher explanation;
- retain unnecessary teacher identity.

## Evidence

Resolution and mastery remain separate, and every derived change points back to
the feedback or existing evidence.
